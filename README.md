# Kettle & Co. – Homepage (React-Bootstrap)

**Library:** React-Bootstrap (with Bootstrap 5 CSS).
**Installed with:** `npm install react-bootstrap bootstrap` inside a Vite React app (`npm create vite@latest`).
**Run it:** `npm install`, then `npm run dev` (or `npm run build` for production).
**Structure:** `src/components/` contains `Navbar`, `Hero`, `Features` and `Footer`, composed in `App.jsx`.
**What the library saved me from writing by hand:** the responsive Navbar, including the mobile hamburger
toggle and collapse behaviour, plus the Grid (`Container`/`Row`/`Col`) and `Card` components.
Without React-Bootstrap I would have needed custom CSS media queries and JavaScript state for the menu.
